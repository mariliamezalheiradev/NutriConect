# NutriConect Front-end (React + Vite)

## Como rodar
1. Instale o Node.js LTS
2. cd frontend
3. npm install
4. Copie o .env.example para .env (copy .env.example .env)
5. npm run dev

Abre em http://localhost:5173 (o back-end precisa estar rodando em http://localhost:8080).

## Pastas
- src/services/api.js: função que chama a API do back-end
